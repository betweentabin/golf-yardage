# 共有する計測データ

アプリの「ゴルフ場」タブ →「共有された計測データ」に並ぶゴルフ場。

追加の手順:
1. アプリで全ホールのグリーンを登録し、「設定」→「このコースを書き出す」で JSON を作る
2. その JSON をこのフォルダに置く（例: `sano-gc.json`）
3. `index.json` に1行追加する

```json
[
  { "id": "<JSON内のコースのid>", "name": "佐野ゴルフクラブ", "file": "sano-gc.json", "verified": true, "note": "出流・駒 36ホール / 2グリーン" }
]
```

`verified` は、現地で全ホールを確かめたら `true`。推定を含むなら `false`（アプリに「要確認」と出る）。
