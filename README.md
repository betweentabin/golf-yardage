# ゴルフ ヤーデージ

iPhone の Safari で動く、グリーンまでの残りヤード表示アプリ。ラウンド中に現在地からグリーン（手前・中心・奥）とピンまでの距離を表示します。

## 公開（GitHub Pages）

1. このフォルダ（`app/`）の中身を GitHub のリポジトリに置く
2. リポジトリの Settings → Pages で、公開するブランチとフォルダを選ぶ
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

位置情報は HTTPS でしか動かないので、ファイルを直接開いても使えません。

## 手元で動かす

```sh
cd app
python3 -m http.server 8765
```

PC のブラウザで `http://localhost:8765/` を開く（localhost は HTTPS 扱い）。
「設定」→「テストモード」をオンにすると、地図を長押し（PC は右クリック）した場所を現在地として試せます。

## 使い方

### ゴルフ場を選んでスタート
1. 「ゴルフ場」タブで名前を検索するか、「現在地の近くを探す」
2. ゴルフ場をタップすると、OpenStreetMap からグリーンとホールを取り込んで保存する（以後は圏外でも使える）
3. OUTスタート（1番から）か INスタート（10番から）を選ぶ。東・西など複数コースがあるゴルフ場はコースごとに、9ホール×複数のゴルフ場は前半・後半の組み合わせで選ぶ
4. グリーンが登録されていないホールは「地図で確認・修正」→「編集」で補う。当日グリーンに立って「現在地を中心に登録」すると、15秒間の平均位置で中心を補正できる
5. Wi-Fi のあるうちに「地図」→「編集」→「表示範囲の写真を保存」しておくと、圏外でも航空写真が見られる

### OpenStreetMap にグリーンがないゴルフ場（日本では多い）
1. ゴルフ場を選ぶと、コース名（例: `出流,駒`）とホール数を聞かれるので答える → ホールの枠ができる
2. 「写真からグリーンを登録」を押し、案内された番号のグリーンの真ん中をタップする
   - 国土地理院の航空写真の色から、グリーンの外形を自動でなぞる（1面 0.5 秒ほど）
   - 2グリーンなら続けて右もタップ。1グリーンなら「次へ」
   - うまくなぞれないとき（影・池・フェアウェイとつながっている等）は、タップ地点を中心だけで登録できる
3. 計測画面の「左／右」は全ホールまとめて切り替わる（その日使う側を一度選べばよい）

登録したら「設定」→「このコースを書き出す」で仲間に共有できる。

### ラウンド中
- 前後ボタンで、選んだ順にホールを進める（「3/18ホール目」と表示）。設定で自動切り替えも可
- 最終ホールの次でラウンド終了
- ピン位置は、中心から奥(+)・手前(-)に yd 単位でずらす。ホールごとに記憶する
- 誤差が精度ゲート（初期値 4m）より悪い間は距離を出さず「測位中」と表示する
- 数秒動かずにいると平均した位置で「確定」になる

### 仲間と共有
「設定」→「このコースを書き出す」で JSON を送り、相手は「ファイルを読み込む」。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html`, `css/style.css` | 画面 |
| `js/geo.js` | 距離計算（Haversine、手前・奥の投影） |
| `js/position.js` | 測位、精度ゲート、静止時の平均化 |
| `js/store.js` | localStorage 保存、JSON 書き出し・読み込み |
| `js/osm.js` | ゴルフ場検索（Nominatim）、グリーン・ホール取り込み（Overpass API） |
| `js/select.js` | ゴルフ場の検索・選択、スタート選択 |
| `js/trace.js` | 航空写真からグリーンの外形を自動でなぞる |
| `js/map.js` | 地図表示と編集（Leaflet） |
| `js/app.js` | 計測画面、設定、画面の常時点灯、ホール自動判定 |
| `sw.js` | オフライン用キャッシュ。ファイルを更新したら `VERSION` を上げる |
