# ゴルフ ヤーデージ

iPhone の Safari で動く、グリーンまでの残りヤード表示アプリ。ラウンド中に現在地からグリーン（手前・中心・奥）とピンまでの距離を表示します。

## 公開（GitHub Pages）

1. このフォルダ（`app/`）の中身を GitHub のリポジトリに置く
2. リポジトリの Settings → Pages で、公開するブランチとフォルダを選ぶ
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

位置情報は HTTPS でしか動かないので、ファイルを直接開いても使えません。

## 手元で動かす

```sh
cd app
python3 -m http.server 8765
```

PC のブラウザで `http://localhost:8765/` を開く（localhost は HTTPS 扱い）。
「コース・設定」→「テストモード」をオンにすると、地図を長押し（PC は右クリック）した場所を現在地として試せます。

## 使い方

### コースを用意する
1. 「地図・編集」でゴルフ場が画面に収まるまで拡大
2. 「編集」→「表示範囲をOSMから取込」
3. 番号のないホールや抜けているグリーンは、「＋ホール」「外形を描く」「番号・Par」で補う
4. 当日グリーンに立って「現在地を中心に登録」すると、15秒間の平均位置で中心を補正できる
5. Wi-Fi のあるうちに「表示範囲の写真を保存」しておくと、圏外でも地図が見られる

### ラウンド中
- 前後ボタンでホールを切り替える（設定で自動切り替えも可）
- ピン位置は、中心から奥(+)・手前(-)に yd 単位でずらす。ホールごとに記憶する
- 誤差が精度ゲート（初期値 4m）より悪い間は距離を出さず「測位中」と表示する
- 数秒動かずにいると平均した位置で「確定」になる

### 仲間と共有
「コース・設定」→「このコースを書き出す」で JSON を送り、相手は「ファイルを読み込む」。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html`, `css/style.css` | 画面 |
| `js/geo.js` | 距離計算（Haversine、手前・奥の投影） |
| `js/position.js` | 測位、精度ゲート、静止時の平均化 |
| `js/store.js` | localStorage 保存、JSON 書き出し・読み込み |
| `js/osm.js` | OpenStreetMap（Overpass API）取り込み |
| `js/map.js` | 地図表示と編集（Leaflet） |
| `js/app.js` | 計測画面、設定、画面の常時点灯、ホール自動判定 |
| `sw.js` | オフライン用キャッシュ。ファイルを更新したら `VERSION` を上げる |
